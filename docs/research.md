# Исследование референсов портфолио видеомонтажёра и режиссёра (.fleur)

## 1. Введение и цели редизайна
Текущая версия сайта `.fleur` страдала от «болезни B2B SaaS»: тёмные карточки с синим неоном (#3B82F6), скруглённые бейджи «Linear/Raycast», отсутствие динамичного видеоряда на первом экране и шаблонные блоки. Для заказчика видеомонтажа (ютуберы, бренды, крипто- и AI-стартапы, режиссёры) такой сайт выглядит обезличенно.

**Цель редизайна:** Превратить лендинг в кинематографичный, тактильный и живой портфолио-сайт премиального видеоредактора с эстетикой профессиональной монтажной студии (DaVinci Resolve / плёнка 35mm / режиссёрский монитор), сохранив высокую скорость загрузки и 100 баллов в Lighthouse.

## 4. Топ-8 ключевых приёмов для внедрения в .fleur

1. **Hero-шоурил первого экрана:** Мгновенный показ динамики монтажа в стилизованном окне монтажного монитора.
2. **Анаморфный интерфейс монтажной стойки:** Таймкоды `00:00:00:00`, маркеры склеек, бейджи форматов `16:9 4K` и `9:16 Shorts`.
3. **Настоящие ссылки на YouTube:** Использование прямых ссылок на ролики автора (`cZZgi5xn930`, `JpYdNQUO9gA`, `W80pFjEQAbk` и др.) с ленивым фасадом YouTube без нагрузки на сеть.
4. **Сплит-слайдер цветокоррекции на реальном материале:** Показ мастерства колориста в DaVinci Resolve без стоковых картинок.
5. **Тёплая кинематографичная палитра (Tungsten Amber / Obsidian):**
   - Фон: Deep Cine Black `#090A0C` (матовый экран аппаратной).
   - Поверхность карточек: Darkroom Slate `#111317`.
   - Акцентный цвет: Tungsten Amber `#E28522` (лампа накаливания 3200K, янтарные маркеры DaVinci).
   - Индикатор записи: REC Red `#EF4444`.
   - Светлая тема: Director's Storyboard Paper `#F7F5F0` с контрастным текстом и терракотовым акцентом `#B85C0A`.
6. **Выверенная шрифтовая пара:**
   - Display: Широкий кинематографичный гротеск `Unbounded` (с поддержкой кириллицы и казахских букв).
   - Body: Читаемый интерфейсный гротеск `Onest`.
   - Code & Meta: `JetBrains Mono` для всех таймкодов, частот кадров и параметров рендера.
7. **Адаптивный свайп-переключатель форматов на мобильных (360px):**
   - Устранение горизонтального скролла в шапке.
   - Компактная фильтрация `16:9 Long-Form` / `9:16 Reels` с оптимизированными превью.
8. **Легковесность и 100 баллов Lighthouse:**
   - Никаких тяжелых внешних библиотек. Нативный `<dialog>` по стандарту Modern Web Guidance.
   - 0 запросов к YouTube до клика пользователя.
